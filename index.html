1. Filter — laag voor laag opgebouwd

1

Alleen HTML

Het verstuurt.

Standaard formulier zonder styling. Versturen herlaadt de pagina — een server zou de gefilterde lijst terugsturen.

Categorie:
  • The Pragmatic Programmer — boeken
  • Clean Code — boeken
  • The Matrix — films
  • Inception — films
  • Discovery — Daft Punk — muziek
2

+ CSS

Het filtert.

:has(option:checked) leest de geselecteerde optie en verbergt items die niet matchen. Nog steeds geen JavaScript nodig.

  • The Pragmatic Programmer
  • Clean Code
  • The Matrix
  • Inception
  • Discovery — Daft Punk
3

+ JavaScript

Het voelt direct.

JS verwijdert de knop, voegt een tekstzoekveld toe en haalt extra data op met fetch().

  • The Pragmatic Programmer
  • Clean Code
  • The Matrix
  • Inception
  • Discovery — Daft Punk
